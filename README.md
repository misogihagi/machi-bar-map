# 街バルマップ

## 1. 背景と動機（Motivation）

現在、全国の商店街や商工会議所が地域振興策として「街バル」を開催していますが、その情報は各地域に散在しており、広域的な集客やアーカイブ化がなされていません。

* **課題:** 地域ごとの情報発信に留まり、全国を網羅したプラットフォームが存在しない。
* **起源と意義:** 函館発祥の「元祖・大門バル」等の歴史を尊重しつつ、地域活性化をデジタル側面から支援する。
* **ビジョン（Global Interest）:** * 単なる利益追求ではなく、サーバー代程度の広告収益を除き、情報は広く公開。
* 機密情報以外の透明性を確保し、公共の利益（国益ならぬ世界益）に資する運営を目指す。
* 自身が推進する**Cloudflare**の活用事例として、モダンなインフラ構成のモデルケースとする。



## 2. 市場環境（Market Analysis）

Googleトレンドの分析によると、街バルの注目度は2010年付近をピークに減少傾向にあり、2020年のパンデミックで底を打ちました。

* **現状:** 存続の危機にある地域イベントも多い。
* **狙い:** 情報のアクセシビリティを高めることで、V字回復のきっかけを作る。

## 3. サービス機能（Features）

ユーザーが「今、行けるバル」を直感的に探せるインターフェースを提供します。

| 機能 | 内容 |
| --- | --- |
| **スポット検索** | Googleマップと連携し、現在地近くで開催中のバルを可視化。 |
| **イベントカレンダー** | 直近および今後の開催スケジュールを一覧表示。 |
| **コンタクト** | 運営への問い合わせや、情報の提供・修正依頼フォーム。 |

---

## 4. 技術スタック（Technical Stack）

「オープン」「透明性」「高効率」を軸とした、メンテナンス性の高い構成を採用します。

### 構成のポイント

* **SSG & GitOps:** * データはYAML形式で管理し、GitHub上で公開。
* 情報の誤りはプルリクエスト（PR）で誰でも修正提案できる「情報の民主化」を実現。


* **Backend / Crawler:** * **Rust**で開発。パフォーマンスを追求し、CLIやWASMとしての展開も視野に入れる。
* **Infrastructure:** * **Cloudflareエコシステム**（Pages, DNS, Hosting, WASM）で完結させ、高速かつ堅牢な配信を行う。
* GCPリソースが発生する場合は**Terraform**でコード管理し、インフラの透明性を確保。



### データ収集ロジック

多くの街バルは「[地域名/団体名] + バル」で検索される傾向があるため、このパターンをベースとしたクローリングアルゴリズムを構築します。

---

## 5. 運営ポリシー

* **非営利性の維持:** 広告掲載は実費（サーバー代等）の補填を目的とし、過度な商業化を避ける。
* **オープンデータ化:** 蓄積された過去の開催データも含め、地域の資産として活用可能な形で保持する。

---

## 6. 街バル情報の抽出（Ollama）

Google検索結果（通常の検索結果リスト＋AI Overview本文）をローカルの LLM に渡し、街バル・はしご酒イベントの情報を構造化して CSV 化する。

### 使用モデル

**`qwen3.5:9b`**（`OLLAMA_MODEL` 環境変数で変更可能）

* GPU なし（CPU 推論）環境では、20B 以上のモデル（`gpt-oss:20b`、`qwen3-coder` 等）は1件あたりの推論が過重で、3,000件規模の処理には現実的でない。
* `qwen3.5:9b` は thinking（思考出力）を無効化（`think: false`）し入力トークンを適正化することで、CPU でも安定して高速・高精度に JSON を抽出できることを確認済み。

### スクリプト

`scripts/extract-machibar-ollama.ts`

| 項目 | 内容 |
| --- | --- |
| **入力** | `data/google-search-results.json` |
| **出力** | `data/machibar-extracted.csv` |
| **中断・再開** | `data/.machibar-progress.json` に処理済みクエリを記録。`Ctrl+C` で停止後、再実行すれば続きから再開 |
| **複数イベントの展開** | 1つの AI Overview に複数の街バルが含まれる場合、行を分割してすべて抽出 |

**抽出カラム:**

1. `query` — 検索クエリ
2. `source` — 元データファイル名
3. `search_name` — 商工会議所・商店街名
4. `has_bar` — 街バル・はしご酒イベントの有無（TRUE / FALSE）
5. `bar_name` — イベント名
6. `official_url` — 公式サイトURL
7. `sns` — SNSアカウント/ページURL
8. `last_held_date` — 最後に開催された日・時期
9. `next_start_date`/`next_end_date` — 次回開催期間（開始日・終了日）
10. `next_venue` — 開催地・会場エリア
11. `lat` / `lng` — 座標（本文中にない場合は空文字）

### 実行コマンド

全件処理:

```bash
bun run extract:machibar
```

件数を制限して試す（例: 10件）:

```bash
LIMIT=10 bun run extract:machibar
```

> [!NOTE]
